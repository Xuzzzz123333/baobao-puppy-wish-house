# 宝宝的小狗心愿屋 / Puppy Wish House

一个以小狗为信使的双人心愿微信小程序。支持心愿和回信、心情天气、共享相册、每日行动与问题、站内信箱，以及可选的微信一次性订阅消息。

原生 JavaScript / WXML / WXSS，后端使用微信云开发。当前为个人学习和体验成员内测项目，尚未正式发布。单账号演示可在「我们 → 单人体验」开启；真实互动需要部署自己的云环境并绑定另一位使用者。
